# Retailer logo assets

Drakes variants are bundled so map labels do not depend on a third-party image request.

- `drakes-dark.png`: official dark lettering with yellow details, from https://drakes.com.au/wp-content/themes/drakes/dist/images/logo_f58734b9.png (retrieved 11 September 2026). Use on light surfaces, including the white store-map marker.
- `drakes-light.svg`: official white lettering with yellow details, from https://dtgxwmigmg3gc.cloudfront.net/images/5a615f7252ba0b73b201addb (retrieved 11 September 2026). Use on dark retailer panels.

Both files preserve the downloaded artwork without recolouring.
